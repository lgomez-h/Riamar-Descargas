# Riamar para Android

Usa la app del bar para consultar tu saldo y registrar tus consumiciones.

## Descargar e instalar

1. Abre en tu móvil Android [Descargar Riamar.apk](https://github.com/lgomez-h/Riamar-Descargas/releases/latest/download/Riamar.apk). No necesitas una cuenta de GitHub.
2. Cuando termine la descarga, abre **Riamar.apk**. Si Android te pide permiso para instalar desde el navegador o la app de archivos, permite la instalación y vuelve al archivo.
3. Pulsa **Instalar** y abre la app. En esta versión, el icono aparece con el nombre **Riamar Pruebas Cloud**. Entra con el usuario y la contraseña que te haya facilitado el bar.

Puedes volver a desactivar el permiso de instalación desde los ajustes de Android después de instalar la app.

## Actualizar la app

Vuelve a [la página de la última versión](https://github.com/lgomez-h/Riamar-Descargas/releases/latest), descarga **Riamar.apk** y ábrelo. Pulsa **Actualizar** cuando Android te lo ofrezca. Mantén instalada la app anterior para actualizarla.

Si necesitas ayuda para instalar la app o acceder a tu cuenta, pregunta en el bar.
